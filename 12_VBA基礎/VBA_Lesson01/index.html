    🎯 このレッスンの目標

    • VBAとは何かを理解する
    • VBE（Visual Basic Editor）を起動できるようになる
    • 標準モジュールを作成できるようになる

    学習時間: 約60分

    1. VBAとは？

    VBAの正式名称

    VBA = Visual Basic for Applications

    Microsoft Office製品（Excel、Word、Accessなど）に搭載されているプログラミング言語です。

    VBAでできること

    できること 具体例
    作業の自動化 毎月の集計作業を1クリックで完了
    大量データ処理 1000件のデータを一瞬で加工
    帳票の自動生成 請求書や報告書を自動作成
    入力フォーム作成 専用の入力画面を作成
    他アプリ連携 OutlookやWordと連携

    なぜVBAを学ぶのか？

    📘 VBA導入によるBefore/After

    VBAを使うことで、手作業では30分〜1時間かかっていた作業が数秒で完了します。 また、人の手による作業ミスを防ぎ、誰がやっても同じ結果を得られます。

    2. 開発タブの表示

    VBAを使うには、まず「開発」タブを表示する必要があります。 初期設定では非表示になっているため、設定を変更します。

    手順

    1. Excelを起動する
    2. ファイル タブをクリック
    3. オプション をクリック
    4. 左メニューから リボンのユーザー設定 を選択
    5. 右側の「メインタブ」一覧で 開発 にチェックを入れる
    6. OK をクリック

    確認

    リボンに「開発」タブが表示されていれば完了です。

    📘 開発タブの位置

    3. VBE（Visual Basic Editor）の起動

    VBEとは？

    VBAのコードを書くための専用エディタ（編集画面）です。 Excelとは別のウィンドウで開きます。

    起動方法

    方法1：ショートカットキー（おすすめ）

    Alt + F11

    最も素早く起動できるので、この方法を覚えておきましょう。

    方法2：開発タブから

    「開発」タブ →「Visual Basic」ボタンをクリック

    VBEの画面構成

    📘 VBE画面構成

    番号 ウィンドウ名 役割
    ① プロジェクトエクスプローラ ファイル・シート・モジュールの一覧表示
    ② コードウィンドウ プログラムを書く場所
    ③ プロパティウィンドウ オブジェクトの設定を変更
    ④ イミディエイトウィンドウ デバッグ（動作確認）に使用

    ウィンドウが表示されていない場合

    「表示」メニューから各ウィンドウを表示できます。

    ウィンドウ ショートカット
    プロジェクトエクスプローラ Ctrl + R
    プロパティウィンドウ F4
    イミディエイトウィンドウ Ctrl + G

    4. 標準モジュールの作成

    モジュールとは？

    プログラム（コード）を書く場所です。用途によって種類が分かれています。

    モジュールの種類 用途
    標準モジュール 汎用的な処理を書く（最もよく使う）
    シートモジュール 特定シートに関連する処理
    ブックモジュール ブック全体に関連する処理
    クラスモジュール オブジェクト指向プログラミング用
    フォームモジュール UserForm用

    今回は 標準モジュール を作成します。

    作成手順

    1. VBEを開く（Alt + F11）
    2. メニューから 挿入 → 標準モジュール を選択
    3. プロジェクトエクスプローラに「Module1」が追加される
    4. 右側にコードウィンドウが表示される

    📘 標準モジュール追加後の構成

    5. はじめてのマクロを書く

    マクロ（プロシージャ）の基本構造

    Sub マクロ名()
    ' ここに処理を書く
End Sub
    要素 説明
    Sub マクロの開始を宣言するキーワード
    マクロ名() マクロに付ける名前（自由に決められる）
    ' コメント シングルクォートで始まる行はコメント（メモ）
    End Sub マクロの終了を宣言するキーワード

    Hello Worldを表示するマクロ

    コードウィンドウに以下を入力してください。

    Sub HelloWorld()
    MsgBox "Hello World!"
End Sub

    コードの解説

    コード 意味
    Sub HelloWorld() 「HelloWorld」という名前のマクロを開始
    MsgBox "Hello World!" メッセージボックスを表示する命令
    End Sub マクロを終了

    入力時の注意点

    • 半角英数字 で入力する（全角だとエラーになる）
    • 大文字・小文字 はVBAが自動調整してくれる
    • スペース は半角スペースを使う
    • 行の先頭の インデント（字下げ）はTabキーで入力

    6. マクロの実行

    実行方法

    方法1：VBEから実行（練習時におすすめ）

    1. 実行したいマクロの中にカーソルを置く
    2. F5 キーを押す

    方法2：Excelから実行

    1. Excelに戻る（Alt + F11）
    2. 「開発」タブ → 「マクロ」をクリック
    3. 実行したいマクロを選択 → 「実行」をクリック

    📘 マクロ実行方法まとめ

    実行結果

    正しく入力できていれば、メッセージボックスに「Hello World!」と表示されます。

    おめでとうございます！ 🎉 これがあなたの最初のVBAプログラムです！

    7. ファイルの保存

    マクロ有効ブックとして保存

    VBAを含むExcelファイルは、通常の .xlsx 形式では保存できません。 マクロ有効ブック（.xlsm） として保存する必要があります。

    保存手順

    1. ファイル → 名前を付けて保存
    2. ファイルの種類を 「Excel マクロ有効ブック (*.xlsm)」 に変更
    3. ファイル名を入力して保存

    📘 ファイル形式の違い

    拡張子 形式 マクロ
    .xlsx Excel ブック 保存できない
    .xlsm Excel マクロ有効ブック 保存できる
    .xls Excel 97-2003 ブック 保存できる（古い形式）

    .xlsx で保存しようとすると警告が表示されます。必ず .xlsm を選んでください。

    8. マクロのセキュリティ設定

    なぜセキュリティ設定が必要？

    マクロは強力な機能を持つため、悪意のあるマクロ（ウイルス）も存在します。 Excelはセキュリティのため、初期設定ではマクロを無効にしています。

    セキュリティ設定の確認・変更

    1. 「開発」タブ → 「マクロのセキュリティ」をクリック
    2. 「マクロの設定」を確認

    📘 セキュリティ設定の種類

    設定 説明 おすすめ
    すべてのマクロを無効にする マクロは一切実行されない ×
    警告を表示してすべてのマクロを無効にする 開くたびに確認メッセージ ◎ 学習時
    デジタル署名されたマクロを除き無効にする 署名付きのみ実行可能 △
    すべてのマクロを有効にする 無条件で実行（危険） ×

    学習時は「警告を表示してすべてのマクロを無効にする」がおすすめです。

    マクロを有効にする方法

    マクロ有効ブックを開くと、上部に警告バーが表示されます。 「コンテンツの有効化」をクリックするとマクロが使えるようになります。

    課題2：複数行のメッセージ

    以下の仕様でマクロを作成してください。

    仕様 - マクロ名：ShowInfo - 動作：メッセージボックスに「VBA学習中」と「がんばります！」を2行で表示する

    ヒント VBAで改行するには `vbCrLf` を使います。 
    MsgBox "1行目" & vbCrLf & "2行目"
    解答例 
    Sub ShowInfo()
    MsgBox "VBA学習中" & vbCrLf & "がんばります！"
End Sub
