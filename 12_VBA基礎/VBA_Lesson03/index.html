    定数と演算子

    🎯 このレッスンの目標

    • 定数（Const）の使い方と利点を理解する
    • 算術演算子を使った計算ができるようになる
    • 比較演算子で値を比較できるようになる
    • 論理演算子で条件を組み合わせられるようになる
    • 文字列結合演算子を使いこなせるようになる

    学習時間: 約60分

    📚 前回の復習

    前回のレッスンで学んだこと：

    • 変数：データを一時保存する箱
    • Dim：変数を宣言するステートメント
    • Option Explicit：変数宣言を強制する設定
    • データ型：String、Long、Double、Date、Boolean

    今回は、変更されない値「定数」と、計算・比較に使う「演算子」を学びます！

    1. 定数（Const）

    定数とは？

    定数は、プログラム実行中に値が変わらないデータです。 変数と違い、一度設定したら変更できません。

    📘 定数と変数の違い

    定数の宣言

    Const 定数名 As データ型 = 値

    具体例

    Const TAX_RATE As Double = 0.1       ' 消費税率 10%
Const MAX_COUNT As Long = 100        ' 最大件数
Const COMPANY_NAME As String = "ABC株式会社"

    なぜ定数を使うのか？

    理由1：意味がわかりやすい

    ' 悪い例：0.1が何を意味するか不明
total = price * 1.1

' 良い例：消費税率であることが明確
Const TAX_RATE As Double = 0.1
total = price * (1 + TAX_RATE)

    理由2：変更が簡単

    消費税率が変わっても、定数の値を1箇所変えるだけでOK！

    ' 税率が8%から10%に変わった場合
Const TAX_RATE As Double = 0.1  ' ここだけ変更すれば全体に反映

    理由3：誤った変更を防ぐ

    Const TAX_RATE As Double = 0.1
TAX_RATE = 0.2  ' コンパイルエラー！定数は変更できない

    定数の命名規則

    定数は大文字とアンダースコアで書くのが一般的です。

    Const MAX_ROWS As Long = 1000
Const DEFAULT_SHEET_NAME As String = "データ"
Const PI As Double = 3.14159

    2. 算術演算子

    基本的な算術演算子

    演算子 意味 例 結果
    + 足し算 10 + 3 13
    - 引き算 10 - 3 7
    * 掛け算 10 * 3 30
    / 割り算 10 / 3 3.333...
    \ 整数の割り算 10 \ 3 3
    Mod 余り 10 Mod 3 1
    ^ べき乗 2 ^ 3 8

    📘 算術演算子一覧

    実践例

    Option Explicit

Sub ArithmeticDemo()
    Dim a As Long, b As Long
    a = 10
    b = 3

    MsgBox "足し算: " & a & " + " & b & " = " & (a + b)      ' 13
    MsgBox "引き算: " & a & " - " & b & " = " & (a - b)      ' 7
    MsgBox "掛け算: " & a & " * " & b & " = " & (a * b)      ' 30
    MsgBox "割り算: " & a & " / " & b & " = " & (a / b)      ' 3.333...
    MsgBox "整数割り算: " & a & " \ " & b & " = " & (a \ b)  ' 3
    MsgBox "余り: " & a & " Mod " & b & " = " & (a Mod b)    ' 1
End Sub

    演算子の優先順位

    数学と同じように、掛け算・割り算が先に計算されます。

    Dim result As Long
result = 2 + 3 * 4     ' 結果は 14（3*4=12 → 2+12=14）
result = (2 + 3) * 4   ' 結果は 20（2+3=5 → 5*4=20）

    優先順位（高い順） 1. ^（べき乗） 2. * /（掛け算・割り算） 3. \（整数割り算） 4. Mod（余り） 5. + -（足し算・引き算）

    迷ったらカッコを使いましょう！

    3. 比較演算子

    比較演算子とは？

    2つの値を比較し、結果を True または False で返します。

    演算子 意味 例 結果
    = 等しい 5 = 5 True
    <> 等しくない 5 <> 3 True
    > より大きい 5 > 3 True
    < より小さい 5 < 3 False
    >= 以上 5 >= 5 True
    <= 以下 5 <= 3 False

    📘 比較演算子一覧

    実践例

    Option Explicit

Sub ComparisonDemo()
    Dim score As Long
    score = 75

    MsgBox "score = 75 の結果: " & (score = 75)   ' True
    MsgBox "score <> 75 の結果: " & (score <> 75) ' False
    MsgBox "score > 60 の結果: " & (score > 60)   ' True
    MsgBox "score >= 80 の結果: " & (score >= 80) ' False
End Sub

    文字列の比較

    文字列も比較できます。

    Dim name As String
name = "田中"

MsgBox name = "田中"    ' True
MsgBox name = "山田"    ' False
MsgBox name <> "山田"   ' True

    4. 論理演算子

    論理演算子とは？

    複数の条件を組み合わせるときに使います。

    演算子 意味 説明
    And かつ 両方Trueのとき True
    Or または どちらかTrueのとき True
    Not 否定 TrueとFalseを反転

    📘 論理演算子の動作

    And（かつ）

    両方の条件が True のとき、結果が True になります。

    Dim age As Long, score As Long
age = 20
score = 80

' 20歳以上 かつ 80点以上
MsgBox (age >= 20) And (score >= 80)  ' True

score = 70
MsgBox (age >= 20) And (score >= 80)  ' False（scoreが80未満）

    Or（または）

    どちらかの条件が True のとき、結果が True になります。

    Dim day As String
day = "土曜日"

' 土曜日 または 日曜日
MsgBox (day = "土曜日") Or (day = "日曜日")  ' True

    Not（否定）

    True と False を反転させます。

    Dim isComplete As Boolean
isComplete = False

MsgBox Not isComplete  ' True（Falseを反転）

    5. 文字列結合演算子

    & 演算子

    文字列を連結するには & を使います。

    Dim firstName As String, lastName As String
firstName = "太郎"
lastName = "山田"

MsgBox lastName & firstName           ' "山田太郎"
MsgBox lastName & " " & firstName     ' "山田 太郎"

    数値と文字列の連結

    & は数値を自動的に文字列に変換します。

    Dim name As String, age As Long
name = "田中"
age = 25

MsgBox name & "さんは" & age & "歳です"  ' "田中さんは25歳です"

    + 演算子との違い

    + でも文字列連結はできますが、数値と混在するとエラーになることがあります。

    ' 安全（推奨）
MsgBox "合計: " & 100    ' "合計: 100"

' 危険（非推奨）
MsgBox "合計: " + 100    ' 型によってはエラーになる

    文字列連結には必ず & を使いましょう！

    6. 実践：消費税計算マクロ

    学んだことを組み合わせて、実用的なマクロを作りましょう。

    Option Explicit

Sub CalculateTaxPrice()
    ' 定数の定義
    Const TAX_RATE As Double = 0.1  ' 消費税率 10%

    ' 変数の宣言
    Dim unitPrice As Long       ' 単価
    Dim quantity As Long        ' 数量
    Dim subtotal As Long        ' 小計（税抜）
    Dim tax As Long             ' 消費税額
    Dim total As Long           ' 合計（税込）

    ' 値の設定
    unitPrice = 1500
    quantity = 3

    ' 計算
    subtotal = unitPrice * quantity
    tax = subtotal * TAX_RATE
    total = subtotal + tax

    ' 結果表示
    MsgBox "【計算結果】" & vbCrLf & _
           "単価: " & unitPrice & "円" & vbCrLf & _
           "数量: " & quantity & "個" & vbCrLf & _
           "小計（税抜）: " & subtotal & "円" & vbCrLf & _
           "消費税（" & TAX_RATE * 100 & "%）: " & tax & "円" & vbCrLf & _
           "合計（税込）: " & total & "円"
End Sub

    課題1：BMI計算

    身長と体重からBMIを計算するマクロを作成してください。

    BMIの計算式: BMI = 体重(kg) ÷ 身長(m)²

    テストデータ - 身長：170cm - 体重：65kg

    ヒント cmをmに変換するには100で割ります。 べき乗は `^` を使います。
    解答例 
    Option Explicit

Sub CalculateBMI()
    Dim heightCm As Double   ' 身長(cm)
    Dim heightM As Double    ' 身長(m)
    Dim weight As Double     ' 体重(kg)
    Dim bmi As Double

    heightCm = 170
    weight = 65

    heightM = heightCm / 100
    bmi = weight / (heightM ^ 2)

    MsgBox "身長: " & heightCm & "cm" & vbCrLf & _
           "体重: " & weight & "kg" & vbCrLf & _
           "BMI: " & Round(bmi, 1)
End Sub

    課題2：割引計算

    商品の価格と割引率から、割引後の価格を計算するマクロを作成してください。

    テストデータ - 定価：5000円 - 割引率：20%

    解答例 
    Option Explicit

Sub CalculateDiscount()
    Const DISCOUNT_RATE As Double = 0.2  ' 20%割引

    Dim originalPrice As Long
    Dim discountAmount As Long
    Dim finalPrice As Long

    originalPrice = 5000
    discountAmount = originalPrice * DISCOUNT_RATE
    finalPrice = originalPrice - discountAmount

    MsgBox "定価: " & originalPrice & "円" & vbCrLf & _
           "割引率: " & DISCOUNT_RATE * 100 & "%" & vbCrLf & _
           "割引額: " & discountAmount & "円" & vbCrLf & _
           "割引後価格: " & finalPrice & "円"
End Sub

    課題3：合否判定の準備

    点数が60点以上かどうかを判定し、結果（True/False）を表示するマクロを作成してください。

    解答例 
    Option Explicit

Sub CheckPass()
    Const PASS_LINE As Long = 60

    Dim score As Long
    Dim isPassed As Boolean

    score = 75
    isPassed = (score >= PASS_LINE)

    MsgBox "点数: " & score & "点" & vbCrLf & _
           "合格ライン: " & PASS_LINE & "点" & vbCrLf & _
           "合格判定: " & isPassed
End Sub
