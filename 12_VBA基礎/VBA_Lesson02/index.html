    1. 変数とは？

    変数＝データを入れる箱

    プログラミングにおける「変数」は、データを一時的に保存しておく箱のようなものです。

    📘 変数のイメージ

    身近な例で理解する

    例1：財布 

    財布 → 今入っている金額を覚えている
朝：5000円
昼食後：4200円（800円使った）

    例2：スマホの連絡先 

    「田中さん」という名前 → 電話番号「090-1234-5678」を記憶

    プログラムでも同じです： - 箱（変数）に名前をつける - 箱の中にデータを入れる - 必要なときにデータを取り出して使う

    2. 変数の宣言（Dim）

    Dimステートメント

    VBAで変数を使うには、まず「この名前の変数を使います」と宣言する必要があります。

    Dim 変数名 As データ型

    具体例

    Dim myName As String    ' 文字列を入れる変数
Dim age As Long         ' 整数を入れる変数
Dim price As Double     ' 小数を入れる変数

    変数への代入

    宣言した変数にデータを入れるには = を使います。

    Dim myName As String
myName = "田中太郎"    ' 変数にデータを代入

Dim age As Long
age = 25               ' 変数に数値を代入

    宣言と代入を同時に行う

    Dim myName As String: myName = "田中太郎"

    ただし、可読性のため別々に書くことが推奨されます。

    3. Option Explicit（変数宣言の強制）

    なぜOption Explicitが必要？

    VBAは初期設定では、宣言していない変数も使えてしまいます。 これが思わぬバグの原因になります。

    バグの例

    Sub BadExample()
    Dim userName As String
    userName = "田中"

    ' スペルミス！（userNameではなくuserNeme）
    MsgBox "こんにちは、" & userNeme & "さん"
End Sub

    このコードを実行すると、userNeme は未宣言の別の変数として扱われ、空白が表示されてしまいます。

    Option Explicitを設定する

    モジュールの一番上に以下を記述します：

    Option Explicit

    これにより、宣言していない変数を使うとエラーになります。

    📘 Option Explicitの効果

    自動設定する方法

    毎回手動で書くのは面倒なので、VBEの設定で自動化しましょう。

    1. VBEメニュー → ツール → オプション
    2. 「編集」タブを選択
    3. 「変数の宣言を強制する」にチェックを入れる
    4. OKをクリック

    これ以降、新しいモジュールには自動的に Option Explicit が追加されます。

    4. 基本的なデータ型

    VBAには様々なデータ型があります。よく使うものを覚えましょう。

    📘 VBAのデータ型一覧

    文字列型：String

    文字の並びを格納します。

    Dim myName As String
myName = "山田花子"

Dim message As String
message = "こんにちは！"

Dim code As String
code = "A001"    ' 数字でも文字列として扱える

    ポイント - 文字列は ダブルクォート（"） で囲む - 数字も文字列として扱える（計算はできない）

    整数型：Long

    整数（小数点なしの数値）を格納します。

    Dim age As Long
age = 25

Dim count As Long
count = 1000

Dim year As Long
year = 2025

    ポイント - 約-21億〜+21億まで扱える - 小数点は扱えない（切り捨てられる） - 昔はIntegerも使われたが、現在はLong推奨

    なぜIntegerではなくLong？

    型 範囲 メモリ
    Integer -32,768 〜 32,767 2バイト
    Long 約-21億 〜 約21億 4バイト

    現代のPCではメモリの差は誤差レベルです。 それより範囲オーバーのエラーを防ぐため、Longを使うのが主流です。

    小数型：Double

    小数点を含む数値を格納します。

    Dim price As Double
price = 1980.5

Dim rate As Double
rate = 0.08    ' 消費税率

Dim average As Double
average = 85.7

    ポイント - 非常に大きな範囲の数値を扱える - 小数点以下も正確に扱える

    日付型：Date

    日付と時刻を格納します。

    Dim today As Date
today = Date    ' 今日の日付

Dim birthday As Date
birthday = #1990/5/15#    ' 日付リテラル

Dim deadline As Date
deadline = "2025/12/31"   ' 文字列からも代入可能

    ポイント - 日付リテラルは # で囲む - Date 関数で今日の日付を取得 - Now 関数で現在の日時を取得

    論理型：Boolean

    真（True）か偽（False） の2値を格納します。

    Dim isComplete As Boolean
isComplete = True

Dim hasError As Boolean
hasError = False

    ポイント - 値は True か False のみ - 条件分岐でよく使う（次回以降で詳しく学習）

    汎用型：Variant

    どんなデータでも格納できる万能型です。

    Dim anything As Variant
anything = "文字列"
anything = 123
anything = #2025/1/1#
anything = True

    ポイント - 便利だが処理速度が遅い - 型が曖昧になりバグの原因に - 基本的には使用を避ける（特別な理由がある場合のみ）

    5. 変数の命名規則

    基本ルール

    ルール OK例 NG例
    英数字とアンダースコア user_name user-name（ハイフン不可）
    先頭は英字 name1 1name（数字始まり不可）
    予約語は使えない myDate Date（VBAの関数名）
    大文字小文字は区別されない UserName = username -

    推奨される命名スタイル

    キャメルケース（単語の区切りを大文字に）

    Dim userName As String
Dim totalPrice As Double
Dim isComplete As Boolean

    意味のある名前をつける

    ' 良い例
Dim customerName As String
Dim orderCount As Long
Dim taxRate As Double

' 悪い例
Dim a As String      ' 何のデータかわからない
Dim x As Long        ' 意味不明
Dim temp As Double   ' 曖昧

    6. 実践：変数を使ったマクロ

    自己紹介マクロ

    Option Explicit

Sub SelfIntroduction()
    ' 変数の宣言
    Dim myName As String
    Dim age As Long
    Dim hobby As String

    ' 変数に値を代入
    myName = "山田太郎"
    age = 28
    hobby = "読書"

    ' 変数を使って表示
    MsgBox "私の名前は" & myName & "です。" & vbCrLf & _
           "年齢は" & age & "歳です。" & vbCrLf & _
           "趣味は" & hobby & "です。"
End Sub

    コードの解説

    コード 意味
    & 文字列を連結する演算子
    vbCrLf 改行を表す定数
    _（アンダースコア） 行を継続する記号

    計算マクロ

    Option Explicit

Sub CalculateTotal()
    ' 変数の宣言
    Dim unitPrice As Long
    Dim quantity As Long
    Dim total As Long

    ' 値を代入
    unitPrice = 1500
    quantity = 3

    ' 計算
    total = unitPrice * quantity

    ' 結果を表示
    MsgBox "単価: " & unitPrice & "円" & vbCrLf & _
           "数量: " & quantity & "個" & vbCrLf & _
           "合計: " & total & "円"
End Sub

    7. よくあるエラーと対処法

    エラー1：変数が定義されていません

    コンパイルエラー: 変数が定義されていません。

    原因: Option Explicit が有効な状態で、宣言していない変数を使った

    対処: 変数名のスペルミスを確認、または Dim で宣言する

    エラー2：型が一致しません

    実行時エラー '13': 型が一致しません。

    原因: データ型に合わない値を代入しようとした

    Dim age As Long
age = "二十五"    ' 文字列を数値型に代入 → エラー

    対処: 正しいデータ型の値を代入する

    エラー3：オーバーフローしました

    実行時エラー '6': オーバーフローしました。

    原因: データ型の範囲を超えた値を代入しようとした

    Dim num As Integer
num = 50000    ' Integerの範囲（32767）を超えている

    対処: より大きな範囲のデータ型（Long）を使う

    項目 内容
    変数とは データを一時保存する箱
    Dim 変数を宣言するステートメント
    Option Explicit 変数宣言を強制する設定
    String 文字列を格納
    Long 整数を格納（推奨）
    Double 小数を格納
    Date 日付・時刻を格納
    Boolean True/Falseを格納
    Variant 何でも格納（非推奨）

    覚えておきたいポイント

    1. Option Explicit は必ず設定する
    2. Integer より Long を使う
    3. Variant は避ける（特別な理由がない限り）
    4. 意味のある変数名をつける

    課題2：消費税計算

    商品の税抜価格から税込価格を計算するマクロを作成してください。

    仕様 - 税抜価格：1980円 - 消費税率：10% - 税込価格を計算して表示

    ヒント 
    Dim taxRate As Double
taxRate = 0.1    ' 10%

Dim taxIncluded As Long
taxIncluded = price * (1 + taxRate)
    解答例 
    Option Explicit

Sub CalculateTax()
    Dim price As Long
    Dim taxRate As Double
    Dim taxIncluded As Long

    price = 1980
    taxRate = 0.1

    taxIncluded = price * (1 + taxRate)

    MsgBox "税抜価格: " & price & "円" & vbCrLf & _
           "消費税率: " & taxRate * 100 & "%" & vbCrLf & _
           "税込価格: " & taxIncluded & "円"
End Sub

    課題3：平均点計算

    3科目のテストの点数から平均点を計算するマクロを作成してください。

    仕様 - 国語：85点 - 数学：72点 - 英語：90点 - 平均点を計算して表示（小数点以下も表示）

    ヒント 平均点は小数になる可能性があるので、Double型を使います。
    解答例 
    Option Explicit

Sub CalculateAverage()
    Dim japanese As Long
    Dim math As Long
    Dim english As Long
    Dim average As Double

    japanese = 85
    math = 72
    english = 90

    average = (japanese + math + english) / 3

    MsgBox "国語: " & japanese & "点" & vbCrLf & _
           "数学: " & math & "点" & vbCrLf & _
           "英語: " & english & "点" & vbCrLf & _
           "平均: " & average & "点"
End Sub
