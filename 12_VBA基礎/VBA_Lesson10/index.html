    Withと処理効率化

    • Calculationで再計算を制御できるようになる
    • 処理速度を大幅に向上させるテクニックを習得する

    学習時間: 約60分

    前回のレッスンで学んだこと：

    • Worksheets：シートの操作
    • Workbooks：ブックの操作

    1. With...End With

    Withとは？

    同じオブジェクトに対する複数の操作をまとめて書ける構文です。

    Before（Withなし）

    Range("A1").Value = "タイトル"
Range("A1").Font.Bold = True
Range("A1").Font.Size = 14
Range("A1").Font.Color = vbBlue
Range("A1").Interior.Color = vbYellow

    After（Withあり）

    With Range("A1")
    .Value = "タイトル"
    .Font.Bold = True
    .Font.Size = 14
    .Font.Color = vbBlue
    .Interior.Color = vbYellow
End With

    📘 Withの効果

    ネストしたWith

    With Range("A1")
    .Value = "タイトル"
    With .Font
        .Bold = True
        .Size = 14
        .Color = vbBlue
    End With
End With

    Withのメリット

    1. コードが短くなる
    2. 可読性が向上
    3. 処理速度が向上（オブジェクト参照が1回で済む）

    2. Setステートメント

    オブジェクト変数とは？

    セルやシートなどのオブジェクトを変数に格納するには Set を使います。

    Dim ws As Worksheet
Set ws = ThisWorkbook.Worksheets("Sheet1")

Dim rng As Range
Set rng = ws.Range("A1:C10")

    SetとLetの違い

    Dim value As String
value = "Hello"      ' Let（省略可能）

Dim ws As Worksheet
Set ws = Worksheets("Sheet1")  ' Set（必須）

    実践例

    Option Explicit

Sub UseObjectVariable()
    Dim ws As Worksheet
    Dim dataRange As Range
    Dim lastRow As Long

    Set ws = ThisWorkbook.Worksheets("データ")
    lastRow = ws.Cells(ws.Rows.Count, 1).End(xlUp).Row
    Set dataRange = ws.Range("A1:C" & lastRow)

    With dataRange
        .Font.Size = 11
        .Borders.LineStyle = xlContinuous
    End With
End Sub

    オブジェクト変数の解放

    処理が終わったら Nothing を代入して解放します。

    Set ws = Nothing
Set rng = Nothing

    3. 画面更新の制御（ScreenUpdating）

    なぜ画面更新を止めるのか？

    VBAの処理中、Excelは逐一画面を更新します。 これを止めると、処理速度が大幅に向上します。

    基本的な使い方

    Sub FastProcess()
    Application.ScreenUpdating = False  ' 画面更新OFF

    ' ここに処理を書く

    Application.ScreenUpdating = True   ' 画面更新ON（必ず戻す！）
End Sub

    📘 ScreenUpdatingの効果

    速度比較

    1000行のデータを処理する場合：

    設定 処理時間（目安）
    ScreenUpdating = True 5秒
    ScreenUpdating = False 0.5秒

    約10倍の高速化！

    4. 再計算の制御（Calculation）

    なぜ再計算を止めるのか？

    セルの値が変わるたびに、Excelは数式を再計算します。 大量のデータ処理時はこれを止めると高速化できます。

    基本的な使い方

    Sub FastCalculation()
    Application.Calculation = xlCalculationManual  ' 手動計算

    ' ここに処理を書く

    Application.Calculation = xlCalculationAutomatic  ' 自動計算に戻す
    Application.Calculate  ' 最後に1回計算
End Sub

    Calculationの設定値

    設定 説明
    xlCalculationAutomatic 自動計算（既定）
    xlCalculationManual 手動計算
    xlCalculationSemiautomatic テーブル以外は自動

    5. その他の高速化テクニック

    イベントの無効化

    Application.EnableEvents = False  ' イベント無効
' 処理
Application.EnableEvents = True   ' イベント有効

    警告ダイアログの非表示

    Application.DisplayAlerts = False  ' 警告OFF
' 削除などの処理
Application.DisplayAlerts = True   ' 警告ON

    カーソル表示の変更

    Application.Cursor = xlWait      ' 砂時計
' 処理
Application.Cursor = xlDefault   ' 通常に戻す

    6. 高速化テンプレート

    推奨テンプレート

    Option Explicit

Sub OptimizedProcess()
    ' 高速化設定
    Application.ScreenUpdating = False
    Application.Calculation = xlCalculationManual
    Application.EnableEvents = False
    Application.Cursor = xlWait

    On Error GoTo ErrorHandler

    '========================================
    ' メイン処理をここに書く
    '========================================


    '========================================

CleanUp:
    ' 設定を元に戻す（必ず実行）
    Application.ScreenUpdating = True
    Application.Calculation = xlCalculationAutomatic
    Application.EnableEvents = True
    Application.Cursor = xlDefault
    Exit Sub

ErrorHandler:
    MsgBox "エラーが発生しました: " & Err.Description
    Resume CleanUp
End Sub

    7. 配列を使った高速化

    セルを1つずつ処理（遅い）

    Sub SlowProcess()
    Dim i As Long
    For i = 1 To 10000
        Cells(i, 1).Value = i
    Next i
End Sub

    配列で一括処理（速い）

    Sub FastProcess()
    Dim data(1 To 10000, 1 To 1) As Variant
    Dim i As Long

    ' 配列に値を格納
    For i = 1 To 10000
        data(i, 1) = i
    Next i

    ' 一括でセルに書き込み
    Range("A1:A10000").Value = data
End Sub

    配列を使うと数十倍高速化！

    8. 実践：高速データ処理マクロ

    Option Explicit

Sub HighSpeedDataProcess()
    Dim ws As Worksheet
    Dim lastRow As Long
    Dim i As Long
    Dim startTime As Double

    ' 開始時刻を記録
    startTime = Timer

    ' 高速化設定
    Application.ScreenUpdating = False
    Application.Calculation = xlCalculationManual

    Set ws = ThisWorkbook.Worksheets("データ")
    lastRow = ws.Cells(ws.Rows.Count, 1).End(xlUp).Row

    ' データ処理
    For i = 2 To lastRow
        With ws
            ' C列 = A列 × B列
            .Cells(i, 3).Value = .Cells(i, 1).Value * .Cells(i, 2).Value

            ' D列 = 判定
            If .Cells(i, 3).Value >= 10000 Then
                .Cells(i, 4).Value = "○"
            Else
                .Cells(i, 4).Value = "×"
            End If
        End With
    Next i

    ' 設定を元に戻す
    Application.Calculation = xlCalculationAutomatic
    Application.ScreenUpdating = True

    ' 処理時間を表示
    MsgBox "処理完了！" & vbCrLf & _
           "処理件数: " & (lastRow - 1) & "件" & vbCrLf & _
           "処理時間: " & Round(Timer - startTime, 2) & "秒"
End Sub

    📝 練習課題

    課題1：書式設定マクロ

    Withを使って、選択範囲に以下の書式を設定するマクロを作成してください。 - フォント：メイリオ、12pt、太字 - 背景色：薄い青 - 罫線：細線

    解答例 
    Sub FormatSelection()
    With Selection
        With .Font
            .Name = "メイリオ"
            .Size = 12
            .Bold = True
        End With
        .Interior.Color = RGB(200, 220, 255)
        .Borders.LineStyle = xlContinuous
    End With
End Sub

    課題2：高速連番マクロ

    A列に1から100000までの連番を高速に入力するマクロを作成してください。 処理時間も表示してください。

    解答例 
    Sub FastNumbering()
    Dim data(1 To 100000, 1 To 1) As Variant
    Dim i As Long
    Dim startTime As Double

    startTime = Timer
    Application.ScreenUpdating = False

    ' 配列に値を格納
    For i = 1 To 100000
        data(i, 1) = i
    Next i

    ' 一括でセルに書き込み
    Range("A1:A100000").Value = data

    Application.ScreenUpdating = True

    MsgBox "完了！処理時間: " & Round(Timer - startTime, 2) & "秒"
End Sub
