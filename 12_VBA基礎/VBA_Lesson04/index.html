    条件分岐

    🎯 このレッスンの目標

    • If...Then...Else文で処理を分岐できるようになる
    • ElseIfを使って複数の条件を判定できるようになる
    • Select Case文で効率的に分岐処理を書けるようになる
    • And/Or/Notを使った複合条件を扱えるようになる

    学習時間: 約70分

    📚 前回の復習

    前回のレッスンで学んだこと：

    • 定数（Const）：変更されない値を定義
    • 比較演算子：=, <>, >, <, >=, <=
    • 論理演算子：And, Or, Not

    今回は、これらを使って「条件によって処理を変える」方法を学びます！

    1. If...Then文（単純な条件分岐）

    基本構文

    If 条件 Then
    ' 条件がTrueのとき実行される処理
End If

    📘 If文の基本構造

    実践例

    Option Explicit

Sub CheckScore()
    Dim score As Long
    score = 75

    If score >= 60 Then
        MsgBox "合格です！"
    End If
End Sub

    1行で書く場合

    処理が1つだけなら、1行で書くこともできます。

    If score >= 60 Then MsgBox "合格です！"

    ただし、可読性のため複数行で書くことを推奨します。

    2. If...Then...Else文（二者択一）

    基本構文

    If 条件 Then
    ' 条件がTrueのとき実行される処理
Else
    ' 条件がFalseのとき実行される処理
End If

    📘 If...Elseの動作

    実践例

    Option Explicit

Sub CheckPassOrFail()
    Dim score As Long
    score = 55

    If score >= 60 Then
        MsgBox "合格です！おめでとうございます！"
    Else
        MsgBox "不合格です。もう一度頑張りましょう。"
    End If
End Sub

    3. If...ElseIf...Else文（複数条件）

    基本構文

    If 条件1 Then
    ' 条件1がTrueのとき
ElseIf 条件2 Then
    ' 条件2がTrueのとき
ElseIf 条件3 Then
    ' 条件3がTrueのとき
Else
    ' どの条件にも当てはまらないとき
End If

    📘 ElseIfによる多分岐

    実践例：成績判定

    Option Explicit

Sub JudgeGrade()
    Dim score As Long
    Dim grade As String

    score = 85

    If score >= 90 Then
        grade = "A（優秀）"
    ElseIf score >= 80 Then
        grade = "B（良好）"
    ElseIf score >= 70 Then
        grade = "C（普通）"
    ElseIf score >= 60 Then
        grade = "D（可）"
    Else
        grade = "F（不可）"
    End If

    MsgBox "点数: " & score & "点" & vbCrLf & _
           "評価: " & grade
End Sub

    注意点：条件の順序

    条件は上から順に評価されます。最初にTrueになった条件の処理だけが実行されます。

    ' 悪い例（score=95でも「60点以上」と表示される）
If score >= 60 Then
    MsgBox "60点以上"
ElseIf score >= 90 Then
    MsgBox "90点以上"  ' ここには到達しない
End If

' 良い例（厳しい条件から先に判定）
If score >= 90 Then
    MsgBox "90点以上"
ElseIf score >= 60 Then
    MsgBox "60点以上"
End If

    4. Select Case文

    基本構文

    Select Case 変数
    Case 値1
        ' 値1のとき
    Case 値2
        ' 値2のとき
    Case Else
        ' どれにも当てはまらないとき
End Select

    📘 Select Caseの構造

    実践例：曜日判定

    Option Explicit

Sub CheckDayOfWeek()
    Dim dayNumber As Long
    Dim dayName As String

    dayNumber = Weekday(Date)  ' 1=日, 2=月, ..., 7=土

    Select Case dayNumber
        Case 1
            dayName = "日曜日"
        Case 2
            dayName = "月曜日"
        Case 3
            dayName = "火曜日"
        Case 4
            dayName = "水曜日"
        Case 5
            dayName = "木曜日"
        Case 6
            dayName = "金曜日"
        Case 7
            dayName = "土曜日"
        Case Else
            dayName = "不明"
    End Select

    MsgBox "今日は" & dayName & "です"
End Sub

    Case の様々な書き方

    Select Case score
    Case 100
        ' 100点のとき
    Case 90, 91, 92, 93, 94, 95, 96, 97, 98, 99
        ' 90〜99点のとき（カンマ区切り）
    Case 80 To 89
        ' 80〜89点のとき（範囲指定）
    Case Is >= 60
        ' 60点以上のとき（比較演算子）
    Case Else
        ' その他
End Select

    If文とSelect Caseの使い分け

    状況 推奨
    2〜3個の条件 If...ElseIf
    4個以上の条件 Select Case
    範囲で判定 どちらでも可
    複合条件（And/Or） If文

    5. 複合条件（And / Or / Not）

    And（かつ）

    両方の条件を満たす場合にTrue

    Option Explicit

Sub CheckAndCondition()
    Dim age As Long
    Dim hasLicense As Boolean

    age = 20
    hasLicense = True

    If age >= 18 And hasLicense = True Then
        MsgBox "運転できます"
    Else
        MsgBox "運転できません"
    End If
End Sub

    Or（または）

    どちらかの条件を満たす場合にTrue

    Option Explicit

Sub CheckWeekend()
    Dim dayName As String
    dayName = "土曜日"

    If dayName = "土曜日" Or dayName = "日曜日" Then
        MsgBox "週末です！"
    Else
        MsgBox "平日です。"
    End If
End Sub

    Not（否定）

    条件を反転させる

    Option Explicit

Sub CheckNotEmpty()
    Dim inputText As String
    inputText = "Hello"

    If Not inputText = "" Then
        MsgBox "入力されています: " & inputText
    Else
        MsgBox "空です"
    End If
End Sub

    複合条件の組み合わせ

    Option Explicit

Sub CheckComplexCondition()
    Dim age As Long
    Dim isMember As Boolean
    Dim hasTicket As Boolean

    age = 25
    isMember = True
    hasTicket = False

    ' 18歳以上で、会員またはチケット所持者
    If age >= 18 And (isMember Or hasTicket) Then
        MsgBox "入場できます"
    Else
        MsgBox "入場できません"
    End If
End Sub

    カッコを使って優先順位を明確にしましょう！

    6. ネスト（入れ子）

    If文の中にIf文を入れることもできます。

    Option Explicit

Sub NestedIfExample()
    Dim score As Long
    Dim attendance As Long

    score = 75
    attendance = 80

    If score >= 60 Then
        If attendance >= 70 Then
            MsgBox "合格です"
        Else
            MsgBox "出席日数が足りません"
        End If
    Else
        MsgBox "点数が足りません"
    End If
End Sub

    ただし、ネストが深くなると読みにくくなるので注意。 複合条件やSelect Caseで書き換えられないか検討しましょう。

    7. 実践：成績判定マクロ

    Option Explicit

Sub GradeJudgment()
    Const PASS_LINE As Long = 60

    Dim name As String
    Dim japanese As Long
    Dim math As Long
    Dim english As Long
    Dim total As Long
    Dim average As Double
    Dim result As String
    Dim grade As String

    ' データ設定
    name = "田中太郎"
    japanese = 78
    math = 65
    english = 82

    ' 計算
    total = japanese + math + english
    average = total / 3

    ' 合否判定
    If average >= PASS_LINE Then
        result = "合格"
    Else
        result = "不合格"
    End If

    ' 評価判定
    Select Case average
        Case Is >= 90
            grade = "S"
        Case Is >= 80
            grade = "A"
        Case Is >= 70
            grade = "B"
        Case Is >= 60
            grade = "C"
        Case Else
            grade = "D"
    End Select

    ' 結果表示
    MsgBox "【成績表】" & vbCrLf & _
           "氏名: " & name & vbCrLf & _
           "国語: " & japanese & "点" & vbCrLf & _
           "数学: " & math & "点" & vbCrLf & _
           "英語: " & english & "点" & vbCrLf & _
           "合計: " & total & "点" & vbCrLf & _
           "平均: " & Round(average, 1) & "点" & vbCrLf & _
           "評価: " & grade & vbCrLf & _
           "判定: " & result
End Sub

    8. まとめ

    このレッスンで学んだこと

    構文 用途
    If...Then 単純な条件判定
    If...Then...Else 二者択一
    If...ElseIf...Else 複数条件の判定
    Select Case 多分岐（4つ以上の条件）
    And / Or / Not 複合条件

    覚えておきたいポイント

    1. 条件は厳しい順から判定する
    2. 複合条件はカッコで明確にする
    3. ネストは2段階までを目安に
    4. 4つ以上の分岐はSelect Caseを検討

    📝 練習課題

    課題1：年齢による料金判定

    年齢に応じた入場料を表示するマクロを作成してください。

    料金表 - 6歳未満：無料 - 6〜12歳：500円 - 13〜64歳：1000円 - 65歳以上：700円

    解答例 
    Option Explicit

Sub CheckAdmissionFee()
    Dim age As Long
    Dim fee As Long

    age = 35

    Select Case age
        Case Is < 6
            fee = 0
        Case 6 To 12
            fee = 500
        Case 13 To 64
            fee = 1000
        Case Is >= 65
            fee = 700
    End Select

    MsgBox "年齢: " & age & "歳" & vbCrLf & _
           "入場料: " & fee & "円"
End Sub

    課題2：うるう年判定

    入力された年がうるう年かどうかを判定するマクロを作成してください。

    うるう年の条件 - 4で割り切れる年はうるう年 - ただし100で割り切れる年は平年 - ただし400で割り切れる年はうるう年

    解答例 
    Option Explicit

Sub CheckLeapYear()
    Dim targetYear As Long
    Dim isLeapYear As Boolean

    targetYear = 2024

    If (targetYear Mod 400) = 0 Then
        isLeapYear = True
    ElseIf (targetYear Mod 100) = 0 Then
        isLeapYear = False
    ElseIf (targetYear Mod 4) = 0 Then
        isLeapYear = True
    Else
        isLeapYear = False
    End If

    If isLeapYear Then
        MsgBox targetYear & "年はうるう年です"
    Else
        MsgBox targetYear & "年は平年です"
    End If
End Sub
