    繰り返し処理

    🎯 このレッスンの目標

    • For...Next文で指定回数の繰り返しができるようになる
    • For Each文でコレクションを処理できるようになる
    • Do...Loop文で条件付きの繰り返しができるようになる
    • Exit文で繰り返しを途中で抜けられるようになる
    • ネストした繰り返し処理を理解する

    学習時間: 約70分

    📚 前回の復習

    前回のレッスンで学んだこと：

    • If...Then...Else：条件による分岐
    • Select Case：複数条件の分岐
    • And / Or / Not：複合条件

    今回は、「同じ処理を繰り返す」方法を学びます！

    1. For...Next文（回数指定の繰り返し）

    基本構文

    For カウンタ変数 = 開始値 To 終了値
    ' 繰り返す処理
Next カウンタ変数

    📘 For...Nextの動作

    実践例：1から10まで表示

    Option Explicit

Sub ForNextBasic()
    Dim i As Long

    For i = 1 To 10
        Debug.Print i
    Next i
End Sub

    Debug.Print はイミディエイトウィンドウ（Ctrl+G）に出力します。

    Stepで増分を指定

    Option Explicit

Sub ForNextStep()
    Dim i As Long

    ' 2ずつ増加（1, 3, 5, 7, 9）
    For i = 1 To 10 Step 2
        Debug.Print i
    Next i

    ' 10から1へ減少
    For i = 10 To 1 Step -1
        Debug.Print i
    Next i
End Sub

    実践例：合計計算

    Option Explicit

Sub CalculateSum()
    Dim i As Long
    Dim total As Long

    total = 0

    For i = 1 To 100
        total = total + i
    Next i

    MsgBox "1から100までの合計: " & total  ' 5050
End Sub

    2. For Each文（コレクションの繰り返し）

    基本構文

    For Each 要素変数 In コレクション
    ' 各要素に対する処理
Next 要素変数

    📘 For Eachの動作

    実践例：全シート名を表示

    Option Explicit

Sub ListAllSheets()
    Dim ws As Worksheet

    For Each ws In ThisWorkbook.Worksheets
        Debug.Print ws.Name
    Next ws
End Sub

    実践例：選択範囲の各セルを処理

    Option Explicit

Sub ProcessSelectedCells()
    Dim cell As Range

    For Each cell In Selection
        If IsNumeric(cell.Value) Then
            cell.Value = cell.Value * 2  ' 数値を2倍
        End If
    Next cell
End Sub

    3. Do...Loop文（条件付き繰り返し）

    前判定（Do While...Loop）

    条件がTrueの間、繰り返します。

    Do While 条件
    ' 繰り返す処理
Loop

    実践例

    Option Explicit

Sub DoWhileExample()
    Dim count As Long
    count = 1

    Do While count <= 5
        Debug.Print "カウント: " & count
        count = count + 1
    Loop
End Sub

    後判定（Do...Loop While）

    最低1回は実行してから条件を判定します。

    Do
    ' 繰り返す処理
Loop While 条件

    Do Until（条件がFalseの間）

    条件がFalseの間、繰り返します。

    Option Explicit

Sub DoUntilExample()
    Dim count As Long
    count = 1

    Do Until count > 5
        Debug.Print "カウント: " & count
        count = count + 1
    Loop
End Sub

    📘 Do...Loopのバリエーション

    4. Exit文（途中脱出）

    Exit For

    For文から抜け出します。

    Option Explicit

Sub ExitForExample()
    Dim i As Long

    For i = 1 To 100
        If i = 5 Then
            MsgBox "5が見つかりました！"
            Exit For  ' ループを抜ける
        End If
        Debug.Print i
    Next i

    MsgBox "ループ終了。i = " & i
End Sub

    Exit Do

    Do文から抜け出します。

    Option Explicit

Sub ExitDoExample()
    Dim count As Long
    count = 0

    Do While True  ' 無限ループ
        count = count + 1
        If count >= 10 Then
            Exit Do  ' 10回で脱出
        End If
    Loop

    MsgBox "ループ回数: " & count
End Sub

    5. ネスト（入れ子）の繰り返し

    九九表の作成

    Option Explicit

Sub CreateMultiplicationTable()
    Dim i As Long, j As Long
    Dim result As String

    For i = 1 To 9
        result = ""
        For j = 1 To 9
            result = result & (i * j) & vbTab
        Next j
        Debug.Print result
    Next i
End Sub

    注意：無限ループに注意

    ' 危険な例（無限ループ）
Dim i As Long
i = 1
Do While i <= 10
    Debug.Print i
    ' i = i + 1 を忘れると無限ループ！
Loop

    対策 - 条件が必ず False になることを確認 - Exit で脱出条件を設ける - デバッグ時は Ctrl+Break で強制停止

    6. 繰り返しの使い分け

    状況 推奨する構文
    回数が決まっている For...Next
    コレクションを処理 For Each
    条件で終了を判定 Do...Loop
    最低1回は実行したい Do...Loop While

    7. 実践：九九表作成マクロ

    Option Explicit

Sub CreateKukuTable()
    Dim i As Long, j As Long
    Dim ws As Worksheet

    ' 新しいシートを作成
    Set ws = ThisWorkbook.Worksheets.Add
    ws.Name = "九九表"

    ' ヘッダー行
    For j = 1 To 9
        ws.Cells(1, j + 1).Value = j
    Next j

    ' ヘッダー列
    For i = 1 To 9
        ws.Cells(i + 1, 1).Value = i
    Next i

    ' 九九の計算結果
    For i = 1 To 9
        For j = 1 To 9
            ws.Cells(i + 1, j + 1).Value = i * j
        Next j
    Next i

    ' 書式設定
    ws.Range("A1:J10").HorizontalAlignment = xlCenter
    ws.Columns("A:J").AutoFit

    MsgBox "九九表を作成しました！"
End Sub

    8. まとめ

    このレッスンで学んだこと

    構文 用途
    For...Next 回数指定の繰り返し
    For Each コレクションの処理
    Do While...Loop 条件がTrueの間繰り返し
    Do Until...Loop 条件がFalseの間繰り返し
    Exit For / Exit Do 繰り返しからの脱出

    覚えておきたいポイント

    1. 回数がわかっているならFor...Next
    2. コレクション処理はFor Each
    3. 無限ループに注意（脱出条件を確認）
    4. Step -1で逆順処理

    📝 練習課題

    課題1：FizzBuzz

    1から30までの数字を表示し、以下のルールで置き換えるマクロを作成してください。

    • 3の倍数 → "Fizz"
    • 5の倍数 → "Buzz"
    • 15の倍数 → "FizzBuzz"
    解答例 
    Option Explicit

Sub FizzBuzz()
    Dim i As Long

    For i = 1 To 30
        If i Mod 15 = 0 Then
            Debug.Print "FizzBuzz"
        ElseIf i Mod 3 = 0 Then
            Debug.Print "Fizz"
        ElseIf i Mod 5 = 0 Then
            Debug.Print "Buzz"
        Else
            Debug.Print i
        End If
    Next i
End Sub

    課題2：素数判定

    2から50までの素数を表示するマクロを作成してください。

    解答例 
    Option Explicit

Sub FindPrimeNumbers()
    Dim num As Long, divisor As Long
    Dim isPrime As Boolean

    For num = 2 To 50
        isPrime = True

        For divisor = 2 To num - 1
            If num Mod divisor = 0 Then
                isPrime = False
                Exit For
            End If
        Next divisor

        If isPrime Then
            Debug.Print num & "は素数"
        End If
    Next num
End Sub
