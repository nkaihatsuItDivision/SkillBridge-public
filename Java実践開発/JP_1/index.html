    第1章 開発環境とプログラムが動く仕組み

    この章で学ぶこと プログラムを書いて動かすための「準備」と、「プログラムが動くとはどういうことか」という土台の感覚を身につけます。 具体的には、(1) 開発に必要な道具をそろえる、(2) プログラムが動く仕組みのイメージをつかむ、(3) 実際に最初のプログラムを動かしてみる、の3ステップで進みます。

    なぜ学ぶのか いきなりコードの書き方から入っても、「そもそもこのコードはどこに書いて、どうやって動かすの?」が分からないと前に進めません。ここでつまずく人はとても多いです。最初に「道具」と「動く仕組み」をおさえておくと、この先の学習がスムーズになります。

    1-1. 開発環境を準備する

    開発環境とは

    プログラムを書いて動かすには、いくつかの道具が必要です。この道具一式のことを 開発環境 と呼びます。料理に例えるなら、包丁やまな板、コンロをそろえるのと同じで、まずこれがないと始まりません。

    ここでは、これから学ぶ Java（ジャバ）というプログラミング言語のために、次の2つを準備します。

    準備するもの これは何か なぜ必要か
    JDK Java を動かすための基本ソフト一式 これがないと、書いた Java のプログラムを動かせません
    エディタ（IDE） プログラムを書くための専用アプリ コードを書いたり、動かしたりする作業場になります

    ① JDK を入れる

    JDK（ジェイ・ディー・ケー）は "Java Development Kit"（Java 開発キット）の略です。Java のプログラムを動かすために必要な道具がまとまったものだと考えてください。

    補足：なぜ JDK が必要なの? 私たちが書く Java のコードは、人間が読みやすい形で書かれています。でもコンピュータはそのままでは理解できません。JDK には、人間が書いたコードをコンピュータが分かる形に「翻訳」する道具が入っています。だから、これがないとプログラムが動かないのです。（翻訳の話は 1-2 でもう少し詳しく説明します）

    JDK は無料で配布されています。「JDK ダウンロード」で検索すると公式の配布ページが見つかります。バージョンや細かいインストール手順は時期によって変わるため、最新の手順は公式の案内に従ってください。

    つまずいたら：入れられたか確認する方法 JDK が正しく入ったかは、パソコンの「コマンドを打つ画面」（Windows なら「コマンドプロンプト」、Mac なら「ターミナル」というアプリ）で次のように打つと確認できます。

    java -version

    バージョン番号が表示されれば、無事に入っています。「コマンドが見つかりません」のようなメッセージが出る場合は、まだ正しく入っていない（またはパソコンが場所を認識していない）状態です。その場合は、もう一度インストール手順を見直してください。

    ② エディタ（IDE）を入れる

    プログラムは「文字」でできているので、文字を書くアプリがあれば書けます。ただし、専用のアプリを使うと、書き間違いを教えてくれたり、ボタン一つで動かせたりと、とても作業がしやすくなります。こうしたプログラミング専用の高機能なアプリを IDE（アイ・ディー・イー、統合開発環境）と呼びます。

    この研修では、次の2つのうちどちらかを使います。

    IDE 特徴
    Eclipse（エクリプス） Java の開発に必要な機能が最初から一通りそろっている。Java 専用ツールとして長く使われている
    VSCode（ブイエス・コード） 軽くて人気のあるエディタ。Java 以外にも幅広く使える。Java を扱うには追加の設定が必要

    どちらを使えばいい? どちらでも構いません。まずはどちらか一方で始めれば十分です。 完全に初めてで迷うなら、Java の機能が最初からそろっている Eclipse のほうが、最初のつまずきは少なめです。VSCode は軽快で将来いろいろな場面で使えるので、慣れてきたら触ってみるとよいでしょう。 どちらも無料です。「Eclipse ダウンロード」「VSCode ダウンロード」で検索すると公式の配布ページが見つかります。インストール手順は公式の案内に従ってください。

    この節のゴール

    • JDK が入っていて、java -version でバージョンが表示される
    • Eclipse または VSCode のどちらかが、自分のパソコンで開ける

    この2つができていれば、プログラムを書いて動かす準備は完了です。

    1-2. プログラムが動くとはどういうことか

    道具がそろったところで、次は「そもそもプログラムはどうやって動いているのか」のイメージをつかみましょう。仕組みが分かっていると、エラーが出たときに「どこで何が起きているか」を考えられるようになります。

    プログラムは「指示書」

    プログラムとは、ひとことで言えばコンピュータへの指示書です。「これを表示して」「この計算をして」「もし○○ならこうして」といった命令を、上から順番に並べたものです。

    コンピュータは、書かれた指示を基本的に上から順に1つずつ実行していきます。人間が手順書を上から読みながら作業するのと同じイメージです。

    書いたコードは、そのままでは動かない（翻訳が必要）

    ここが大事なポイントです。私たちが書く Java のコードは、人間が読み書きしやすい言葉で書かれています。しかしコンピュータは、その言葉を直接は理解できません。コンピュータが本当に分かるのは、もっと機械寄りの形式だからです。

    そこで、人間が書いたコードを、コンピュータが分かる形に翻訳するという作業が必要になります。Java では、この翻訳をする道具が 1-1 で入れた JDK に含まれています。

    流れをイメージにすると、こうなります。

    人間が書いた Java のコード
        │
        ▼  （翻訳する）
コンピュータが分かる形
        │
        ▼  （実行する）
       結果（画面に表示される、など）

    補足：「翻訳」と「実行」は別の段階 「翻訳でつまずく」のか「実行した結果がおかしい」のかは、別の問題です。 たとえば、書き方のルールを間違える（カッコの閉じ忘れなど）と、そもそも翻訳の段階で止まります。一方、翻訳は通ったけれど計算結果が想定と違う、という場合は実行の段階の問題です。 この2つを区別できると、エラーが出たときに原因を切り分けやすくなります。今は「翻訳の段階」と「実行の段階」があるんだな、と知っておくだけで十分です。

    エラーは「悪いこと」ではない

    学び始めると、エラー（うまく動かないときに出るメッセージ）に必ず出会います。最初は不安になりますが、エラーはコンピュータからの「ここがおかしいよ」というお知らせです。むしろ親切な機能です。

    エラーメッセージには、何が・どこでおかしいかのヒントが書かれています（多くは英語ですが、慣れれば読めるようになります）。エラーが出たら、まずメッセージを落ち着いて読む。これがプログラミング上達のいちばんの近道です。

    1-3. 最初のプログラムを動かしてみる

    いよいよ、実際にプログラムを書いて動かしてみましょう。最初のプログラムは、伝統的に「画面に文字を表示するだけ」のシンプルなものから始めます。

    書いてみるコード

    public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

    これを動かすと、画面に次のように表示されます。

    Hello, World!

    たった1行を表示するだけですが、「自分が書いたものがコンピュータの上で動いた」という最初の一歩です。

    実際に動かす手順

    では、このコードを実際に動かしてみましょう。ここでは、準備したエディタ（IDE）を使った、いちばん基本的な動かし方を説明します。

    前提：エディタ（IDE）と、Java を動かすための JDK が、すでにパソコンに入っているものとします。まだの場合は、このあとの実機での準備で揃えます。お使いのエディタによって画面や名前が少しずつ違うので、ここでは共通する流れを説明します。細かいボタンの位置などは、実際の画面を見ながら、講師や周りの人に確認してください。

    ① ファイルを作る

    エディタで、新しいファイルを作ります。ファイル名は Hello.java とします。

    ここで大事なのは、ファイル名（Hello）と、コードの中の class のあとの名前（Hello）を、同じにすることです。Java では「public class Hello と書いたら、ファイル名は Hello.java」という決まりがあります。ここが食い違うと、うまく動きません。

    public class Hello {     ← この「Hello」と
    ...
}
    ↑ コードの中の名前 Hello と、ファイル名 Hello.java をそろえる

    ② コードを書く（打ち込む）

    作った Hello.java に、さきほどのコードを書きます。最初は、見ながらそのまま打ち込んでみてください（コピーせず手で打つと、より身につきます）。

    public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

    ③ 保存する

    書けたら、ファイルを保存します（多くのエディタで Ctrl + S、Mac では Command + S）。保存しないと、書いた内容が反映されないことがあるので、動かす前に保存する習慣をつけましょう。

    ④ 実行する（動かす）

    いよいよ実行します。多くのエディタには、実行ボタン（▶ のような三角の印）があります。それを押すと、プログラムが動きます。

    エディタによっては、コードの main の行のあたりに「Run（実行）」というボタンや表示が出るので、それを押す形のこともあります。「実行」「Run」といったメニューから動かす方法もあります。お使いのエディタでの実行方法を、最初に確認しておくとよいです。

    ⑤ 結果を確認する

    実行すると、エディタの下のほうにある「コンソール」や「ターミナル」と呼ばれる黒い（または白い）画面に、結果が表示されます。

    Hello, World!

    この Hello, World! が表示されれば、大成功です。あなたが書いたプログラムが、はじめて動きました。

    つまずきポイント：思ったとおりに動かないとき 最初は、なかなか一発で動かないものです。よくあるつまずきと対処を挙げておきます。 - ファイル名とクラス名が違う：Hello.java と public class Hello の名前をそろえる - 保存し忘れ：動かす前に保存（Ctrl + S）したか確認する - 打ち間違い：;（セミコロン）や " "（ダブルクォーテーション）の付け忘れ、つづりの間違いがないか見直す - 赤い印やエラーメッセージが出る：エディタがどの行がおかしいか教えてくれていることが多いので、その行を見直す うまくいかなくても、それは失敗ではなく、ふつうの過程です。次の「プログラムが動くとはどういうことか」で、エラーとの付き合い方も説明します。

    コードの中身を見てみる

    今の段階では、すべてを完全に理解する必要はありません。ただ、初めて見る言葉が並んでいて不安になると思うので、ざっくり何が書いてあるかだけ説明します。「今は雰囲気だけ分かればよい」という気持ちで読んでください。それぞれの詳しい意味は、この先のトピックで順番に学びます。

    public class Hello {          ← ①「Hello」という名前のプログラムのまとまり
    public static void main(String[] args) {   ← ② プログラムが動き出す入口
        System.out.println("Hello, World!");   ← ③ 画面に文字を表示する命令
    }
}
    印 部分 今のところの理解
    ① public class Hello { ... } プログラム全体を包む「箱」。Hello はこの箱につけた名前です
    ② public static void main(String[] args) { ... } プログラムが動き出す入口。Java はここから実行が始まる、という決まりです
    ③ System.out.println("...") かっこの中の文字を画面に表示する命令。" " で囲んだ部分が表示されます

    補足：難しそうな ① と ② について public class static void といった単語は、今はまだ「おまじない」だと思って大丈夫です。Java では「プログラムはこの形で書き始める」という決まりがあり、最初はその形をそのまま真似すればOKです。意味は後のトピック（クラスやメソッドを学ぶところ）で分かってきます。 今この章で本当に注目してほしいのは ③ の System.out.println(...) です。これは「かっこの中身を画面に表示する」という、とてもよく使う命令です。

    表示する文字を変えてみる

    理解を深めるいちばんの方法は、自分で少しいじってみることです。③ の " " の中身を書き換えると、表示される文字が変わります。

    System.out.println("はじめてのプログラム");

    これに変えて動かすと、画面には次のように表示されます。

    はじめてのプログラム

    このように、" " の中を変えれば好きな文字を表示できます。

    つまずきポイント：" "（ダブルクォーテーション）を忘れずに 文字を表示するときは、表示したい文字を " " で囲む必要があります。これを書き忘れたり、片方だけにしたりすると、翻訳の段階でエラーになります。 また、行の終わりの ;（セミコロン）も Java では必要です。「1つの命令の終わりには ; をつける」という決まりがあります。これも忘れるとエラーになりやすいので、最初のうちは特に意識してみてください。

    1-4. 練習問題

    手を動かして確認しましょう。まず自分で考えてみて、わからなくなったら「解答・解説を見る」をクリックして確認してください。

    問1. 画面に、自分の名前を表示するプログラムを動かしてみましょう。たとえば「田中太郎」と表示させるには、どう書けばよいでしょうか。

    解答・解説を見る 
    System.out.println("田中太郎");
    **解説** - `System.out.println(...)` は「かっこの中身を画面に表示する」命令です。 - 表示したい文字（田中太郎）を `" "` で囲んで、かっこの中に入れます。 - 行の終わりに `;`（セミコロン）をつけるのを忘れないようにしましょう。 なお、この1行は 1-3 で出てきた `main` の中（②の入口の中）に書きます。プログラム全体としては次のような形になります。 
    public class MyName {
    public static void main(String[] args) {
        System.out.println("田中太郎");
    }
}

    問2. 次のコードには、間違いが1か所あります。どこが間違っているか、なぜ間違いなのかを答えてください。

    System.out.println(こんにちは);
    解答・解説を見る **間違い：表示したい文字が `" "` で囲まれていない** **正しくは：** 
    System.out.println("こんにちは");
    **解説** - 文字を表示するときは、その文字を `" "`（ダブルクォーテーション）で囲む必要があります。 - 囲まずに `こんにちは` と書くと、Java はそれを「文字」ではなく「何かの名前（変数など）」だと受け取ろうとして、「そんな名前のものはない」とエラーになります。 - 「画面に出したい文字は `" "` で囲む」と覚えておきましょう。

    問3. 次のコードを動かすと、画面にどう表示されるでしょうか。予想してみてください。

    System.out.println("おはよう");
System.out.println("こんにちは");
System.out.println("こんばんは");
    解答・解説を見る **答え：3行にわたって、次のように表示されます。** 
    おはよう
こんにちは
こんばんは
    **解説** - プログラムは、書かれた命令を**上から順に1つずつ**実行します（1-2 で学んだ通りです）。 - `System.out.println(...)` は、表示したあとに**改行する**命令です。そのため、3つの命令がそれぞれ別の行に表示されます。 - 「上から順に実行される」という感覚は、これからずっと使う大事な土台です。

    この章のまとめ

    • プログラムを書いて動かすには 開発環境（JDK と エディタ／IDE）が必要
    • IDE は Eclipse か VSCode のどちらかを使えばよい。迷ったらまず Eclipse
    • プログラムはコンピュータへの指示書で、書かれた命令を上から順に実行する
    • 私たちが書いたコードは、翻訳されてからコンピュータの上で実行される
    • エラーは「ここがおかしい」というお知らせ。落ち着いてメッセージを読むことが上達の近道
    • System.out.println("...") で、かっこの中の文字を画面に表示できる。文字は " " で囲み、行末に ; をつける

    次の章へ 次は、プログラムの中で「数」や「文字」といったデータを扱うための変数を学びます。この章で動かした「表示する」プログラムに、いろいろなデータを組み合わせられるようになっていきます。
