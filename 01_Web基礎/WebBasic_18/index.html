    3. バリデーション機能の実装（レッスン3の技術）

    ✅ ステップ4: 必須項目の設定

    レッスン3で学んだバリデーション機能を追加しましょう。

    以下の項目にrequired属性を追加してください：

    <!-- お名前を必須に -->
<input type="text" id="name" name="name" placeholder="例：山田太郎" required>

<!-- メールアドレスを必須に -->
<input type="email" id="email" name="email" placeholder="例：yamada@example.com" required>

<!-- 年齢を必須に -->
<input type="number" id="age" name="age" placeholder="例：25" required>

<!-- お問い合わせ種別を必須に -->
<select id="category" name="category" required>

<!-- お問い合わせ内容を必須に -->
<textarea id="message" name="message" placeholder="お問い合わせ内容を詳しくお書きください" required></textarea>

<!-- 個人情報の取り扱いを必須に -->
<input type="checkbox" id="privacy" name="privacy" required>

    ✅ 確認： 空欄で送信ボタンを押して、エラーメッセージが表示されることを確認してください。

    ✅ ステップ5: より詳細なバリデーション

    さらに詳細なバリデーションを追加しましょう：

    <!-- フリガナにカタカナパターンを追加 -->
<input type="text" id="kana" name="kana" placeholder="例：ヤマダタロウ" 
       pattern="[ァ-ヴー]+" title="カタカナで入力してください">

<!-- 電話番号にパターンを追加 -->
<input type="tel" id="phone" name="phone" placeholder="例：090-1234-5678" 
       pattern="[0-9]{2,4}-[0-9]{2,4}-[0-9]{3,4}" title="ハイフン区切りで入力してください">

<!-- 年齢に範囲を追加 -->
<input type="number" id="age" name="age" placeholder="例：25" 
       min="1" max="120" required>

<!-- 名前に文字数制限を追加 -->
<input type="text" id="name" name="name" placeholder="例：山田太郎" 
       maxlength="50" required>

<!-- メールアドレスに文字数制限を追加 -->
<input type="email" id="email" name="email" placeholder="例：yamada@example.com" 
       maxlength="100" required>

<!-- お問い合わせ内容に文字数制限を追加 -->
<textarea id="message" name="message" placeholder="お問い合わせ内容を詳しくお書きください（500文字以内）" 
          maxlength="500" required></textarea>

    ✅ 確認： - フリガナに「やまだ」と入力して送信 → パターンエラー - 年齢に「0」と入力して送信 → 範囲エラー

    🔄 振り返りポイント

    • required属性で必須項目を設定
    • pattern属性で入力パターンを制限
    • min/max属性で数値範囲を制限
    • maxlength属性で文字数を制限
    • title属性でユーザーへのヒント提供

    5. Formspree.io連携（実際の送信機能）

    📧 ステップ10: Formspree.io設定

    📘 Formspree導入ガイド

    実際にメールを送信できるようにしましょう。

    10-1. Formspree.ioアカウント作成

    1. Formspree.io(https://formspree.io/) にアクセス
    2. 「Get Started」をクリック
    3. メールアドレスとパスワードを入力してアカウント作成
    4. メール認証を完了

    10-2. フォーム作成

    1. ダッシュボードで「New Form」をクリック
    2. フォーム名を入力（例：「お問い合わせフォーム」）
    3. 通知先メールアドレスを入力
    4. 「Create Form」をクリック

    10-3. エンドポイントURLの取得

    作成後に表示されるエンドポイントURLをコピーします：

    https://formspree.io/f/YOUR_FORM_ID

    🔧 ステップ11: フォームの設定変更

    HTMLの<form>タグを以下のように変更してください：

    <!-- 修正前 -->
<form method="POST">

<form action="https://formspree.io/f/YOUR_FORM_ID" method="POST">

    💡 重要： YOUR_FORM_ID の部分を、実際に取得したエンドポイントURLに置き換えてください。
