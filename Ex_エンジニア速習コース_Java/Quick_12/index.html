    文字列操作

    🎯 このレッスンの目標

    • Stringクラスの主要メソッドを使える
    • 文字列の検索・置換・分割ができる
    • 文字列の比較を正しくできる
    • StringBuilderを使える

    学習時間: 約2時間

    1. 文字列の基本

    Stringは参照型

    String message = "Hello, World!";
String empty = "";      // 空文字列
String blank = "   ";   // 空白のみ

    文字列の連結

    String firstName = "太郎";
String lastName = "田中";

// +演算子
String fullName = lastName + " " + firstName;
System.out.println(fullName);  // 田中 太郎

// concat()メソッド
String name = lastName.concat(firstName);
System.out.println(name);  // 田中太郎

    2. 文字列の比較

    ==ではなくequals()を使う

    String s1 = "Hello";
String s2 = "Hello";
String s3 = new String("Hello");

// ❌ ==は参照の比較（アドレス）
System.out.println(s1 == s2);   // true（たまたま同じ）
System.out.println(s1 == s3);   // false

// ✅ equals()は内容の比較
System.out.println(s1.equals(s2));  // true
System.out.println(s1.equals(s3));  // true

    大文字小文字を無視して比較

    String s1 = "Hello";
String s2 = "HELLO";

System.out.println(s1.equals(s2));           // false
System.out.println(s1.equalsIgnoreCase(s2)); // true

    3. 文字列の長さと取得

    length() - 文字数を取得

    String text = "Hello";
System.out.println(text.length());  // 5

    charAt() - 指定位置の文字を取得

    String text = "Hello";
System.out.println(text.charAt(0));  // H
System.out.println(text.charAt(4));  // o

    substring() - 部分文字列を取得

    String text = "Hello, World!";

System.out.println(text.substring(0, 5));   // Hello（0〜4）
System.out.println(text.substring(7));      // World!（7以降）

    4. 検索メソッド

    indexOf() - 位置を検索

    String text = "Hello, World!";

System.out.println(text.indexOf("o"));       // 4（最初のo）
System.out.println(text.lastIndexOf("o"));   // 8（最後のo）
System.out.println(text.indexOf("Java"));    // -1（見つからない）

    contains() - 含むかどうか

    String text = "Hello, World!";

System.out.println(text.contains("World"));  // true
System.out.println(text.contains("Java"));   // false

    startsWith() / endsWith()

    String filename = "report.pdf";

System.out.println(filename.startsWith("report"));  // true
System.out.println(filename.endsWith(".pdf"));      // true
System.out.println(filename.endsWith(".txt"));      // false

    5. 変換メソッド

    大文字・小文字変換

    String text = "Hello, World!";

    空白除去

    String text = "  Hello, World!  ";

    8. StringBuilder

    文字列を効率的に組み立てる

    // ❌ 非効率（毎回新しいStringオブジェクトが作られる）
String result = "";
for (int i = 0; i < 1000; i++) {
    result += i;
}

// ✅ 効率的
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    sb.append(i);
}
String result = sb.toString();

    StringBuilderの主なメソッド

    StringBuilder sb = new StringBuilder();

sb.append("Hello");        // 末尾に追加
sb.append(" ");
sb.append("World");
System.out.println(sb);    // Hello World

sb.insert(6, "Java ");     // 位置6に挿入
System.out.println(sb);    // Hello Java World

sb.delete(6, 11);          // 位置6〜10を削除
System.out.println(sb);    // Hello World

sb.reverse();              // 逆順
System.out.println(sb);    // dlroW olleH

String result = sb.toString();  // Stringに変換

    9. 実践：ユーザー入力の検証

    public class InputValidator {
    public static void main(String[] args) {
        String email = "  User@Example.COM  ";
        String phone = "090-1234-5678";

        // メールアドレスの正規化
        String normalizedEmail = email.trim().toLowerCase();
        System.out.println("正規化: " + normalizedEmail);

        // メールアドレスの検証
        if (normalizedEmail.contains("@") && normalizedEmail.contains(".")) {
            System.out.println("有効なメールアドレスです");
        }

        // 電話番号からハイフンを除去
        String phoneDigits = phone.replace("-", "");
        System.out.println("電話番号（数字のみ）: " + phoneDigits);

        // 電話番号の桁数チェック
        if (phoneDigits.length() == 11) {
            System.out.println("有効な電話番号です");
        }
    }
}

    10. まとめ

    よく使うメソッド一覧

    メソッド 説明 例
    length() 文字数 "Hello".length() → 5
    equals() 比較 "A".equals("A") → true
    substring() 部分取得 "Hello".substring(0,2) → "He"
    indexOf() 位置検索 "Hello".indexOf("l") → 2
    contains() 含むか "Hello".contains("ll") → true
    toUpperCase() 大文字化 "Hello".toUpperCase() → "HELLO"
    toLowerCase() 小文字化 "Hello".toLowerCase() → "hello"
    trim() 空白除去 " Hi ".trim() → "Hi"
    replace() 置換 "Hello".replace("l","L") → "HeLLo"
    split() 分割 "a,b,c".split(",") → ["a","b","c"]

    🔑 重要ポイント

    • 文字列比較はequals()を使う
    • trim()で前後の空白を除去
    • 大量の連結はStringBuilderを使う
