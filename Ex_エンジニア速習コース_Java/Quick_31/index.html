    3. Repository - 検索メソッドの追加

    命名規則によるメソッド自動生成

    @Repository
public interface StudentRepository extends JpaRepository<Student, Long> {

    // 名前で部分一致検索
    List<Student> findByNameContaining(String name);

    // 学部で検索
    List<Student> findByDepartment(String department);

    // 名前と学部で検索
    List<Student> findByNameContainingAndDepartment(String name, String department);

    // 年齢以上
    List<Student> findByAgeGreaterThanEqual(Integer age);
}

    メソッド命名規則

    キーワード 説明 例
    findBy 検索の開始 findByName
    Containing 部分一致 findByNameContaining
    And AND条件 findByNameAndAge
    Or OR条件 findByNameOrAge
    GreaterThan より大きい findByAgeGreaterThan
    LessThan より小さい findByAgeLessThan
    Between 範囲 findByAgeBetween
    OrderBy 並び替え findByNameOrderByAgeDesc

    4. Service - 検索ロジック

    @Service
public class StudentService {

    @Autowired
    private StudentRepository studentRepository;

    // 条件付き検索
    public List<Student> search(String keyword, String department) {
        // 両方指定
        if (keyword != null && !keyword.isEmpty() && 
            department != null && !department.isEmpty()) {
            return studentRepository.findByNameContainingAndDepartment(keyword, department);
        }
        // キーワードのみ
        if (keyword != null && !keyword.isEmpty()) {
            return studentRepository.findByNameContaining(keyword);
        }
        // 学部のみ
        if (department != null && !department.isEmpty()) {
            return studentRepository.findByDepartment(department);
        }
        // 条件なし（全件）
        return studentRepository.findAll();
    }
}

    5. Controller - パラメータ受け取り

    @Controller
@RequestMapping("/students")
public class StudentController {

    @Autowired
    private StudentService studentService;

    // 一覧表示（検索対応）
    @GetMapping
    public String index(@RequestParam(required = false) String keyword,
                        @RequestParam(required = false) String department,
                        Model model) {
        List<Student> students = studentService.search(keyword, department);

        model.addAttribute("students", students);
        model.addAttribute("keyword", keyword);      // 検索条件を保持
        model.addAttribute("department", department);

        return "students/index";
    }

    // ... 他のメソッド ...
}

    @RequestParam

    属性 説明
    required = false パラメータ省略可能
    defaultValue = "" デフォルト値

    7. @Queryによるカスタムクエリ

    複雑な検索条件

    @Repository
public interface StudentRepository extends JpaRepository<Student, Long> {

    // JPQL（Java Persistence Query Language）
    @Query("SELECT s FROM Student s WHERE s.name LIKE %:keyword% OR s.department LIKE %:keyword%")
    List<Student> searchByKeyword(@Param("keyword") String keyword);

    // ネイティブSQL
    @Query(value = "SELECT * FROM students WHERE age >= :minAge AND age <= :maxAge", 
           nativeQuery = true)
    List<Student> findByAgeRange(@Param("minAge") int minAge, @Param("maxAge") int maxAge);
}

    StudentRepository.java

public interface StudentRepository extends JpaRepository<Student, Long> {
    List<Student> findByNameContaining(String name);
    List<Student> findByDepartment(String department);
    List<Student> findByNameContainingAndDepartment(String name, String department);

    StudentService.java（検索部分）

    public List<Student> search(String keyword, String department) {
    boolean hasKeyword = keyword != null && !keyword.isEmpty();
    boolean hasDepartment = department != null && !department.isEmpty();

    if (hasKeyword && hasDepartment) {
        return studentRepository.findByNameContainingAndDepartment(keyword, department);
    } else if (hasKeyword) {
        return studentRepository.findByNameContaining(keyword);
    } else if (hasDepartment) {
        return studentRepository.findByDepartment(department);
    }
    return studentRepository.findAll();
}

    model.addAttribute("students", students);
    model.addAttribute("keyword", keyword);
    model.addAttribute("department", department);
    return "students/index";

    9. まとめ

    検索機能の実装ポイント

    層 役割
    View 検索フォーム、検索条件の保持
    Controller @RequestParamでパラメータ取得
    Service 条件分岐による検索ロジック
    Repository findByXxx メソッドの定義

    Repository命名規則

    findBy + フィールド名 + 条件キーワード

例：findByNameContaining("田")
    → name LIKE '%田%'

    🔑 重要ポイント

    • 検索はGETメソッドで（URLで条件共有可能）
    • 検索条件をViewに戻す（入力値を保持）
    • 空文字とnullの両方をチェック
