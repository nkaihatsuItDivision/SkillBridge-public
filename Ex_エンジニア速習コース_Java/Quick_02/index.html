    HTML基礎

    🎯 このレッスンの目標

    • HTMLの役割を理解する
    • 基本的なHTMLタグを使えるようになる
    • 文書構造を作成できるようになる
    • リスト・リンク・画像・表を作成できるようになる

    学習時間: 約2時間

    1. HTMLとは？

    HTMLの役割

    HTML（HyperText Markup Language） = Webページの「構造」を作る言語

    言語 役割 例え
    HTML 構造（骨組み） 家の柱や壁
    CSS 見た目（装飾） 壁紙や家具
    JavaScript 動き（機能） 電気や水道

    HTMLの特徴

    • タグで文書の構造を表す
    • ブラウザがHTMLを読んで画面に表示する
    • .htmlという拡張子で保存する

    2. HTMLの基本構造

    最小限のHTML

    <!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <title>ページタイトル</title>
</head>
<body>
    ここに本文を書く
</body>
</html>

    各部分の説明

    タグ 説明
    <!DOCTYPE html> HTML5文書であることを宣言
    <html lang="ja"> HTML全体を囲む（日本語ページ）
    <head> ページの設定情報（画面には表示されない）
    <meta charset="UTF-8"> 文字コード（日本語を正しく表示）
    <title> ブラウザのタブに表示されるタイトル
    <body> 画面に表示される内容

    3. 基本的なタグ

    見出しタグ（h1〜h6）

    <h1>大見出し（1ページに1つ）</h1>
<h2>中見出し</h2>
<h3>小見出し</h3>
<h4>さらに小さい見出し</h4>

    💡 h1が最も大きく、h6が最も小さい

    段落タグ（p）

    <p>これは段落です。文章のまとまりを表します。</p>
<p>2つ目の段落です。自動的に改行されます。</p>

    改行タグ（br）

    <p>1行目<br>2行目<br>3行目</p>

    💡 <br>は閉じタグ不要

    強調タグ

    <strong>重要な文字（太字）</strong>
<em>強調したい文字（斜体）</em>

    4. リスト

    順序なしリスト（ul）

    <ul>
    <li>項目1</li>
    <li>項目2</li>
    <li>項目3</li>
</ul>

    表示結果: - 項目1 - 項目2 - 項目3

    順序ありリスト（ol）

    <ol>
    <li>手順1</li>
    <li>手順2</li>
    <li>手順3</li>
</ol>

    表示結果: 1. 手順1 2. 手順2 3. 手順3

    5. リンク

    基本的なリンク

    <a href="https://www.google.com">Googleへ</a>

    別タブで開く

    <a href="https://www.google.com" target="_blank">Googleへ（別タブ）</a>

    ページ内リンク

    <!-- リンク元 -->
<a href="#section1">セクション1へジャンプ</a>

<!-- リンク先 -->
<h2 id="section1">セクション1</h2>

    6. 画像

    基本的な画像表示

    <img src="image.jpg" alt="画像の説明">
    属性 説明
    src 画像ファイルのパス
    alt 画像が表示できない時の代替テキスト

    サイズ指定

    <img src="image.jpg" alt="画像の説明" width="300" height="200">

    7. 表（テーブル）

    基本的な表

    <table border="1">
    <tr>
        <th>名前</th>
        <th>年齢</th>
        <th>職業</th>
    </tr>
    <tr>
        <td>田中太郎</td>
        <td>25</td>
        <td>エンジニア</td>
    </tr>
    <tr>
        <td>佐藤花子</td>
        <td>30</td>
        <td>デザイナー</td>
    </tr>
</table>

    表のタグ

    タグ 説明
    <table> 表全体
    <tr> 行（table row）
    <th> 見出しセル（table header）
    <td> データセル（table data）

    表示結果:

    名前 年齢 職業
    田中太郎 25 エンジニア
    佐藤花子 30 デザイナー

    8. div と span

    divタグ（ブロック要素）

    <div>
    <h2>セクション1</h2>
    <p>セクション1の内容です。</p>
</div>
<div>
    <h2>セクション2</h2>
    <p>セクション2の内容です。</p>
</div>
    • グループ化に使う
    • 前後で改行される

    spanタグ（インライン要素）

    <p>この文章の<span style="color: red;">ここだけ</span>赤くする</p>
    • 文章の一部に使う
    • 前後で改行されない

    9. 実践：自己紹介ページを作ろう

    完成イメージ

    以下の要素を含むページを作成します： - 見出し（名前） - 自己紹介文 - 趣味リスト - スキル表

    サンプルコード

    <!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <title>自己紹介 - 山田太郎</title>
</head>
<body>
    <h1>山田太郎</h1>

    <h2>自己紹介</h2>
    <p>はじめまして、山田太郎です。<br>
    Webエンジニアを目指して勉強中です。</p>

    <h2>趣味</h2>
    <ul>
        <li>プログラミング</li>
        <li>読書</li>
        <li>映画鑑賞</li>
    </ul>

    <h2>スキル</h2>
    <table border="1">
        <tr>
            <th>スキル</th>
            <th>レベル</th>
        </tr>
        <tr>
            <td>HTML/CSS</td>
            <td>学習中</td>
        </tr>
        <tr>
            <td>Java</td>
            <td>これから</td>
        </tr>
    </table>

    <h2>リンク</h2>
    <p><a href="https://github.com" target="_blank">GitHub</a></p>
</body>
</html>

    10. まとめ

    このレッスンで学んだこと

    カテゴリ タグ
    基本構造 <!DOCTYPE>, <html>, <head>, <body>
    見出し・段落 <h1>〜<h6>, <p>, <br>
    リスト <ul>, <ol>, <li>
    リンク <a href="">
    画像 <img src="" alt="">
    表 <table>, <tr>, <th>, <td>
    グループ化 <div>, <span>

    タグの書き方ルール

    <タグ名>内容</タグ名>        <!-- 基本形 -->
<タグ名 属性="値">内容</タグ名>  <!-- 属性あり -->
<タグ名>                    <!-- 閉じタグ不要（br, imgなど） -->

    📝 練習課題

    以下の内容を含むHTMLファイルを作成してください：

    1. ページタイトル: 「私の好きなもの」
    2. 大見出し（h1）: ページのタイトル
    3. セクション1: 好きな食べ物（順序なしリスト）
    4. セクション2: 好きな映画トップ3（順序ありリスト）
    5. セクション3: プロフィール表（名前・年齢・出身地）
    解答例 
    <!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <title>私の好きなもの</title>
</head>
<body>
    <h1>私の好きなもの</h1>

    <h2>好きな食べ物</h2>
    <ul>
        <li>ラーメン</li>
        <li>寿司</li>
        <li>カレー</li>
    </ul>
